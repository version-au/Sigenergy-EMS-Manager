Map this app to your Sigenergy Local Modbus entities. Start typing to search your Home Assistant entities.

Schedules

Each schedule window is applied while active, and re-applied automatically if something else changes the values during that window. Power fields are entered in kW and converted to your entities' native unit (set via the add-on's "power_entities_unit" option — default kW). Use the arrows to reorder — when two active schedules overlap, whichever is lower in the list wins on any field they both set.
